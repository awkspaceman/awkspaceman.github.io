# 罗柯岚 & 张倩 · 婚礼邀请 Demo

纯 HTML / CSS / JavaScript；无需安装依赖或自建服务器。酒红与奶油白视觉，手机及桌面布局。

## 开启 GitHub Pages

打开仓库 Settings → Pages：

1. Source 选择 Deploy from a branch。
2. Branch 选择 main，目录选择 / (root)。
3. 点击 Save，等待 GitHub 的 pages build and deployment 完成。

目标网站地址：https://awkspaceman.github.io/

## 已实现

- 打开请柬、邀请 / 行程 / 赴约切换。
- 出席与缺席分支、1–12 人计数、饮食及留言。
- 全体同行者住宿；默认每间最多 2 人，房间数向上取整，可增加房间；不足容量时阻止预览。
- 姓名必填、回执预览、保存和清除当前浏览器中的演示回执。
- 不使用外部字体、图片、追踪器或第三方脚本。

## Demo 边界

日期、时间、场地和酒店均待确认。回执不上传、不通知新人、不跨设备同步。正式对宾客开放收集前，必须接入在线表单或其他托管数据服务；不能把 localStorage 当作共享数据库。真实宾客名单与回执不要写入公开仓库。
